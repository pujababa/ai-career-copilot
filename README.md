# AI Career Copilot 🚀

An AI-powered web application to help students with career guidance, placement tracking, and technical learning.

## 🌐 Live Demo
https://ai-career-copilot-rwi0.onrender.com

## ✨ Features
- 🤖 AI Chat System (with smart fallback responses)
- 🎯 Career Assessment Quiz
- 📊 Placement Tracker
- 👨‍💼 Admin Panel
- 🔐 Authentication System

## 🛠 Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- SQLite
- Google Gemini API
- Render (Deployment)

## 🚀 How to Run Locally
1. Clone the repo
2. Install dependencies:
   pip install -r requirements.txt
3. Add `.env` file with GEMINI_API_KEY
4. Run:
   python app.py
